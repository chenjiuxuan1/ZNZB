# DS 多项目与每小时看板发现设计

## 目标

1. 每个国家允许配置多个 DolphinScheduler 项目名称。
2. 六国新增看板统一显示为“每小时监控”，并使用相同名称匹配巡检规则。
3. 看板发现支持当前国家和六国批量执行；发现失败必须显示实际原因，成功后立即变为可执行。

## 方案

- 项目名称输入支持英文逗号、中文逗号、分号和换行，后端统一拆分、去重并逐个解析项目码。
- 配置新增 `projects[country]` 明细，同时保留 `projectNames`、`projectCodes` 兼容旧配置。巡检逐项目执行并按国家聚合，单个项目失败不会阻断其他项目。
- 六份来源配置的目标看板标题改为“每小时监控”，规则标题正则同步调整。
- inventory API 新增六国批量发现入口，复用单国发现逻辑。页面提供“一键发现六国”，并展示每个国家的成功或失败原因。

## 验收标准

- 输入 `项目A，项目B; 项目C\n项目A` 保存后得到三个唯一项目，并分别显示匹配状态。
- DS 测试会扫描所有成功匹配的项目，部分失败时仍返回其余项目结果。
- 六国 inventory 中目标来源均显示“每小时监控”，规则可匹配该标题。
- 单国或六国发现成功后卡片清单立即刷新；鉴权或网络失败时保留待发现并展示明确错误。
