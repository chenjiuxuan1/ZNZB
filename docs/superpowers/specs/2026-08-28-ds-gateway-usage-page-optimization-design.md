# DS 网关使用统计页面整体优化设计

## 目标

在不改变现有 API、权限判断和数据结构的前提下，将“DS 网关使用统计”改造成更容易扫描和操作的管理工作台。重点解决页面过长、内容全宽拉伸、卡片嵌套过多、说明文字过密、用户配置区域难以快速定位的问题。

## 范围

- 优化整个“DS 网关使用统计”页面，包括使用概览、国家分布、Token 明细、全局策略、模拟校验、违规记录、用户列表和策略下发。
- 保留现有数据请求、保存、校验、封锁、移除配置和策略生成行为。
- 不修改服务端接口、权限模型、限额计算或审计统计口径。

## 页面结构

### 页面头部

- 使用统一的页面标题、简短说明、更新时间和刷新操作。
- 核心指标保持首屏可见，并通过一致的数字层级强化总请求量、成功率、使用人数和风险操作。
- 将状态反馈放在主要操作附近，避免用户在页面中寻找刷新结果。

### 使用概览

- 国家使用概览作为快速扫描区，国家、用户次数和异常状态对齐展示。
- 时间筛选集中到单一工具栏，并明确其影响范围。
- 国家详情与 Token 明细使用一致的表格、标签和数值格式，减少视觉跳变。
- 为宽屏内容设置合理最大宽度；小屏允许表格局部横向滚动，不让整个页面溢出。

### 权限管控

- 全局策略和模拟校验保持双栏工作区，窄屏自动切换为单栏。
- 违规记录位于用户配置之前，优先暴露需要处理的问题。
- 用户列表采用紧凑摘要行；展开后才显示角色、删除权限、黑名单、Token 和独立限额。
- 增加用户搜索与状态筛选，便于在 39 人及以上列表中定位目标。
- 分页控制仅保留一处，显示当前范围和总数。
- “封锁”“移除配置”等危险操作与普通操作在颜色和位置上明确区分。

### 策略下发

- 将下发区域设计为页面收尾操作，展示当前拦截状态、Token 数和默认角色。
- 使用明确的主按钮文案和简短结果反馈，不重复长篇部署说明。

## 视觉系统

- 沿用现有浅色管理台风格和蓝色主色，不引入新的设计语言。
- 采用 8px 为主的间距体系，统一区块间距、表单间距和按钮高度。
- 减少厚边框、重复圆角容器和大面积空白；用背景层级和分组标题组织内容。
- 正文与表单说明保持可读字号；数值列使用等宽数字。
- 状态颜色保持语义一致：绿色为正常、琥珀色为提醒、红色为违规或危险操作。

## 交互与状态

- 用户搜索匹配用户名和 Token；状态筛选支持全部、已配置、默认角色、正常、超限或封锁。
- 搜索或筛选变化后回到第一页，分页只针对筛选后的结果。
- 展开用户行时保留所有既有编辑能力。
- 加载、空结果、错误和成功状态使用现有反馈组件，但文案更短、更靠近相关区域。
- 所有按钮保留键盘焦点样式，移动端主要操作具备足够点击面积。

## 测试与验收

- 为用户筛选、分页范围和空结果增加纯函数测试，采用现有 `node:test` 风格。
- 运行 DS 使用统计相关测试和完整测试集。
- 在桌面宽屏、常规桌面、平板和手机宽度检查无页面级横向滚动。
- 对照改版前后截图检查信息层级、表格密度、用户展开状态和危险操作辨识度。
- 浏览器控制台不得出现新增错误。

## 非目标

- 不新增后端搜索或分页接口。
- 不修改 token 到用户的映射机制。
- 不调整角色定义、动作分类或限额默认值。
- 不对侧边栏或其他值班平台页面做全站重构。
